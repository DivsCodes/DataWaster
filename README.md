# Data Waster

A simple, modern web app that lets you intentionally consume internet bandwidth by downloading real data.

Built with pure **HTML, CSS, and JavaScript**, with no installation or backend required.

## Features

- Live data usage counter
- Real-time download speed
- Peak speed tracking
- Custom data targets
- Quick presets — 100 MB, 500 MB, 1 GB, 5 GB
- Pause and resume
- Stop anytime
- Elapsed time and ETA
- Live download speed graph
- Local session history
- Responsive design for desktop and mobile
- Clean dark interface
- Infinite mode for continuous downloading

## How It Works

The app repeatedly downloads real data from the internet and tracks the amount transferred.

Everything runs directly in your browser. There is:

- No software installation
- No backend server
- No access to your personal files
- No cryptocurrency mining
- No special permissions required

**Note:** Running the tool intentionally uses your internet bandwidth and may consume a large amount of data.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Open the project folder and launch:

```text
index.html
```

That's it. No Node.js or additional dependencies are required.
